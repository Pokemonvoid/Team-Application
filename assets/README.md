# Project assets

Sedimite (067), Scraqua (036), Hydrena (037) and Corrupted Hydrena (037-anomaly) are copied unchanged from the Pokemon Void wiki repository. The wiki repository was used read-only. Original project credits and rights remain with Pokemon Void and its artists.

The outlined and unoutlined Team Void marks in brand/ were supplied by Ed for this recruitment website. The outlined mark is used in the header and favicon; the other version is retained for future use. Neither artwork has been redrawn.

Pixelify Sans is the display typeface used by the Void wiki. Its license is bundled in fonts/OFL.txt. Body text uses the reader's installed Verdana or sans-serif font.

Application Guide

Help

The application is split into short sections so you always know what you are being asked and what comes next.

How to apply

  1. Open the application form.
  2. Sign in with Discord when the live connection is available.
  3. Answer the general questions.
  4. Select one or more open roles.
  5. Answer the questions for the roles you selected.
  6. Review everything and submit.

Who can apply?

Applicants of any age may apply. The age question uses broad brackets only: Under 18, 18–24, 25–29, and 30+.

Applications are currently open for Programmer, Move Animator, Spriter, and Music. Other roles are temporarily closed.

Applying for more than one role

You can select multiple roles in the same application. The form will show the relevant questions for each one, so you do not need to submit separate applications.

Portfolio and work examples

If your role benefits from examples, include links to work you are comfortable sharing with the recruitment team. Large video submissions do not need to be uploaded through the application form; the Directors can arrange those separately when needed.

What happens after submission?

Your application enters the private Director review queue. If there is an update, the recruitment system may notify you through Discord. If the Directors want to continue, you may receive a private recruitment ticket for follow-up questions.

Some applicants may later be invited to a secluded area of the development server for a live conversation before final onboarding.

Discord sign-in

The portal uses Discord sign-in to identify your account. Authentication is performed by Discord. The recruitment site should never ask you to type your Discord password or 2FA code into a Pokémon Void form.

Recruitment Data

Privacy

This page describes the intended data boundaries for the recruitment portal. It should be reviewed again before live applications are enabled.

Discord account security

Discord authentication is handled through Discord OAuth. Pokémon Void does not need your Discord password, 2FA code, passkey, or Discord session credentials. The backend only keeps the account information required to identify your recruitment profile.

Where application data belongs

The public website files may be hosted on GitHub Pages, but application answers, recruitment records, interview contents, access tokens, secrets, and database credentials must not be stored in the public website repository.

Private recruitment data is intended to be handled by the Cloudflare backend and its database, with access controlled server-side.

Who can review applications?

The Director portal is intended for authorised recruitment Directors only. Opening the public admin.html address must never be enough to access data; every protected request must also be authorised by the backend.

Interview confidentiality

The interview ticket system is being designed separately from ordinary application storage because the Directors want stronger confidentiality for interview conversations. It will not be treated as complete until its access and encryption model has been reviewed and approved.

Uploads and links

Initial applications should prefer links for larger work samples, especially video. This reduces unnecessary storage of large personal files. Any future direct-upload feature should use private backend storage rather than the public site repository.

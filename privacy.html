Privacy & Account Safety

A plain-language summary of how the recruitment portal is intended to handle applicant information.

Discord sign-in

The production portal will use Discord OAuth. Your Discord password, 2FA code, passkey, or Discord session credentials are not collected by this website. Sign-in happens on Discord's own authorization page.

Application data

  • The public website repository contains frontend files only.
  • Application answers, applicant records, status history, and private ticket data belong on the protected Cloudflare backend.
  • Secrets, database credentials, authentication secrets, and encryption keys must never be committed to the public frontend repository.
  • Director/admin access must be checked by the backend on every protected request.

Interview privacy

The final interview encryption design is being handled separately from the public frontend. The intended access model is Director and interviewee only. The live interview system should not be enabled until that model is agreed and tested.
